# Why the flags differ from the shipped makefile:
#  -D_DARWIN_C_SOURCE is REQUIRED on macOS and is the only substantive change.
#   src/rtkcmn.c begins with "#define _POSIX_C_SOURCE 199506", which restricts
#   the macOS system headers to POSIX.1-1996. snprintf was introduced in C99
#   and POSIX.1-2001, so the header correctly hides it and the build fails with
#   "call to undeclared library function 'snprintf'". Defining _DARWIN_C_SOURCE
#   restores the full Darwin namespace. This is a portability defect in RTKLIB
#   on macOS, not a defect in the toolchain, and no RTKLIB source was modified.
#  -Wno-unused-variable silences one warning in rtkcmn.c and affects nothing.
# The RTKLIB source tree is otherwise untouched: verify with 'git status' in a
# fresh clone at the commit above.
